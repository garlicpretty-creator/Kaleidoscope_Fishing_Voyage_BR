## 3. 拒絕的四種聲音
在工作站故意做錯，聽得出四種不同：
- [ ] 缺東西（手上東西不對）：低音＋灰煙。
- [ ] 還沒好（正在做）：兩下輕響＋小氣泡（氣泡在空氣中看不看得到？）。
- [ ] 滿了：水聲或木頭聲＋往上彈的粒子。
- [ ] 這裡不行（位置不對）：石頭聲＋紅色塵土。

## 4. 物品說明
- [ ] 破紀錄的魚只看到 ★（沒有公分數）；拿去做魚拓，魚拓上的魚大小跟長度有關。
- [ ] 釣竿說明是三個小圖（鉤、線、浮標）；魚卵說明是那條魚的小圖。
- [ ] 1.5.0 舊存檔裡「★ 45 cm」的魚：放進魚缸再拿出來，變成只有 ★。

## 5. 魚簍
- [ ] 裝魚時圖示會變（空、一點、半滿、快滿、滿）：一條銀尾巴 → 一銀一金兩條尾巴 → 簍口塞滿、露出魚頭 → 魚堆出簍口、一條垂到簍邊。
- [ ] 使用打開的格子只有圖，點一格取出那種魚；蹲下使用全部倒在腳邊。
- [ ] 創造模式選單只有空的魚簍。
- [ ] 1.5.0 舊存檔的魚簍裡的魚還在。

## 6. 撈網與魚池（最需要看）
- [ ] 撈網的合成（木棍 ×2、線 ×3、漁網）。
- [ ] 撈網拿在手上是 3D 模型（握把纏繩、木框、網袋），第一與第三人稱都是網框朝上、握在手裡（握法照竹釣竿，若歪了或穿進手裡請截圖）。
- [ ] 對池裡游的那條魚使用，撈到的就是那條；對水面使用撈到離準心最近的。
- [ ] 池裡的魚看得出大小（小、中、大）；餓的游在上面、偶爾冒一串泡；吃飽的游低一點。
- [ ] 食槽四段看得出剩多少飼料。
- [ ] 空手點餵食台：有魚卵就取出；沒有就所有魚游過來（點名）。
- [ ] 長大一級時魚跳出水面濺水花。
- [ ] 海水池偶爾有白色鹽花；放鹽時一陣白霧。
- [ ] 撈網對木盆撈魚苗、對魚缸取魚。

## 7. 漁販
- [ ] 訂單魚下面有一排木牌（淡木色、有穿繩孔），交一條翻一塊（紅漆面、金色魚印）；木牌置中的方向對不對（少於 8 塊時整排在魚的正下方，不是偏向一邊）。
- [ ] 交齊時點頭、小聲的升級音效、綠色粒子。
- [ ] 賣想收的魚叮兩聲、一般的一聲、養殖的一聲較低。
- [ ] 錢袋空了：搖頭攤手。
- [ ] 1.5 的 8 種新魚會出現在扁擔上（當天想收）。

## 8. 曬魚架、魚拓、海鷗
- [ ] 鹽水蝦能掛上曬魚架，一串四隻、尾巴朝上掛著的彎蝦（看得到體節和眼睛），顏色從粉橘、紅到紅褐；一天後變帶殼蝦乾。
- [ ] 8 種新魚的魚拓：橫放、和舊魚拓同一種墨色（菌褶鰈、孢子海馬、櫻鱒、溪蝦、回音魟、幽匿燈籠魚、流星旗魚、極光銀魚）；舊魚拓的樣子和 1.5.0 一樣。
- [ ] 海鷗在遠一點的地方不會突然消失或卡住。

## 9. 漁港的聲音
- [ ] 站在碼頭或水上的木板：偶爾有木板聲、繩子聲、浪聲，不會太吵。

- [ ] 坐小船：船身吱嘎；魚艙有魚時偶爾拍一下；拖網時有水聲。
- [ ] 夜晚漁燈旁很小的嗡聲。
