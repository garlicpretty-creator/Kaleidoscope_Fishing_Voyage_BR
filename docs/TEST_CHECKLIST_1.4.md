# 森羅物語：漁歌 1.4.0 遊戲內檢測表

這份表只列**必須進遊戲才看得出來**的項目。規則和數字類的行為已經在遊戲外自動驗證過（見最後一節），不用重測。

- 測試環境：Minecraft 基岩版 1.26.30 以上，森羅物語：廚房 1.6.1 以上，兩邊的行為包與資源包都啟用。
- 建議開一個創造模式的新世界，再切生存模式測消耗與耐久。
- 標 **★** 的是 1.4.0 新增或改動、最可能出問題的地方，請優先測。
- 測到不對的，請記下是哪一項、看到什麼；內容日誌有訊息的話一起附上。

## 3. 潮汐鐘 ★

模型位置和兩個 Molang 查詢（`q.time_of_day`、`q.moon_phase`）只能在遊戲裡確認。

- [ ] 工作台合成：中間一個時鐘，上下左右各一個銅錠
- [ ] 拿在手上（第一人稱與第三人稱）看得到圓盤，位置與大小合理，沒有穿進手裡或飄在空中
- [ ] 指針會隨時間轉；`/time add 3000` 後轉了四分之一圈
- [ ] 指針在遠端藍色弧段時，手帳潮汐頁顯示漲潮；離開弧段時同時變成退潮
- [ ] 指針是順時針轉（如果是逆時針，告訴我，改一個負號就好）
- [ ] 小月亮跟天上的月相一致：滿月四條全亮、新月全暗；`/time add 24000` 逐天看 8 個月相
- [ ] 虧月亮的是左半、盈月亮的是右半（相反的話告訴我）
- [ ] 放進物品展示框是靜態圖示（預期如此）
