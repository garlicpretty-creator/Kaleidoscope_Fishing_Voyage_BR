# 森羅物語：漁歌 1.4.0 遊戲內檢測表

自動檢查（`build.py check`、`validate.py`、`check_models.py`、ESLint）都通過，但都沒有進過遊戲。
這張表列的是只有在遊戲裡才看得出來的東西。

- 測試環境：Minecraft 基岩版 1.26.30 以上，森羅物語：廚房 1.6.1 以上，兩邊的行為包與資源包都啟用。
- 建議開一個創造模式的新世界，再切生存模式測消耗與耐久。
- 標 **★** 的是這一輪改過或刪過東西的地方，優先測。

## 0. 載入

- [ ] 進世界後內容日誌沒有 `[Fishing Voyage]` 開頭的錯誤，也沒有腳本載入失敗的訊息 **★**
- [ ] 日誌出現 `Registered N Cookery recipes`（沒有 `Kaleidoscope Cookery did not answer`）
- [ ] 森羅手帳裡出現「漁歌」分頁，圖示與分類都正常
- [ ] 創造模式物品欄：漁歌的物品都有名稱和圖示，沒有紫黑格或 `item.xxx.name`
- [ ] 三種語言（English、繁體中文、简体中文）切換後名稱都正常

## 1. 物品欄圖示 ★

這一輪刪掉了 11 個方塊的平面 icon，它們應該照舊顯示成 3D 方塊。

- [ ] 曬魚架、魚案板、漁獲秤、魚缸、漁燈、漁網、蝦籠、漁具架、錨、漁獲木箱、魚露甕：物品欄與手上都是 3D 模型，沒有缺貼圖
- [ ] 玻璃浮球、漁網牆飾、魚乾串、魚拓、紫菜礁、牡蠣床、昆布茶：仍是平面 icon
- [ ] 宴席物品（生魚片船、鮪魚大體等）與大魚缸：仍是平面 icon
- [ ] 四種生物的生怪蛋圖示正常

## 2. 釣魚基本流程

- [ ] 竹釣竿拋竿：浮標飛出、落水後浮在水面，看得到釣線
- [ ] 咬鉤時有水花與音效，約 2 秒內再用一次能上鉤
- [ ] 錯過咬鉤後會重新等待，不會卡住
- [ ] 收空竿、切換手上物品、走遠超過 32 格：浮標都會消失
- [ ] 退出世界再進來，沒有殘留的浮標
- [ ] 生存模式：釣到魚扣釣竿耐久，耐久用完釣竿會斷
- [ ] 第三人稱與另一位玩家看到的釣線起點在釣竿尖端

## 3. 收線小遊戲與拉扯

- [ ] 有體長的魚上鉤後出現小遊戲（動作列的軌道），按住與放開使用鍵能控制方框
- [ ] 贏了魚上岸，輸了浮標彈起並重新等待
- [ ] 蝦、螃蟹、牡蠣、垃圾與寶物直接上岸，不進小遊戲
- [ ] `/scriptevent kaleidoscope_fishing:minigame off` 後改成拉扯模式：魚拉扯時硬收會斷線，喘息時收線能拉近 **★**
- [ ] `... minigame on`、`status`、`charset ascii`、`charset block` 都有回覆並生效 **★**

## 4. 水域與漁獲

- [ ] 河流、湖、海、深海、沼澤、海灘各釣幾條，魚種符合手帳的出沒提示
- [ ] 紅樹林沼澤與櫻花樹林的水域：漁獲正常，鮭魚不會異常地多 **★**（這裡修過寒冷判定）
- [ ] 雪地或冰原的水域：寒冷魚種（香魚、鮭魚、秋刀魚、帝王蟹）仍然比較常見 **★**
- [ ] 地底洞穴的水（Y 48 以下、頭上有遮蔽）：只釣到洞穴魚種
- [ ] 末地的水池：只釣到末地魚種，浮標換成末地外觀
- [ ] 白天與夜晚、下雨與放晴各試一次，漁獲有差別
- [ ] 釣到的魚名稱下方有 ◆、◆◆ 或 ◆◆◆；破紀錄的魚有 ★ 與體長

## 5. 四種釣竿

- [ ] 竹釣竿、漁歌釣竿可用工作台合成
- [ ] 漁歌釣竿在鍛造台用獄髓升級模板與獄髓錠升級成熔岩釣竿
- [ ] 熔岩釣竿能在下界岩漿釣魚，漁獲落在腳邊
- [ ] 漁歌釣竿掛在漁具架上，用末影之眼對它使用，變成末影釣竿，耐久、附魔與部件都保留
- [ ] 末影釣竿在末地島邊緣往虛空拋竿，浮標懸在半空，能釣到虛空魚種
- [ ] 四種釣竿都能在附魔台或鐵砧上附魔

## 6. 釣具部件與餌

- [ ] 鉤、線、浮標各裝一個到漁具架上的釣竿，釣竿說明出現部件名稱
- [ ] 換同一格的部件時，舊的會還給你；用剪刀可拆下全部部件
- [ ] 裝上浮標後浮標外觀改變，裝上線後釣線顏色改變
- [ ] 假餌鉤：背包沒有餌也能釣到魚
- [ ] 背包裡的餌在魚上鉤時消耗一個（創造模式不消耗）
- [ ] 斗笠、蓑衣能穿戴，模型顯示正常

## 7. 傳說魚

條件很嚴，建議用指令調時間與天氣。

- [ ] 河伯鯰：雷雨、骨鉤、漁歌釣竿以上
- [ ] 藍鰭皇鮪：滿月、漲潮、下雨、活蝦當餌、漁歌釣竿以上
- [ ] 冰湖主：新月的黎明，冰洞或冰封水域
- [ ] 熔岩龍鯉：下界岩漿、鋼絲線、背包裡沒有任何餌
- [ ] 傳說魚上鉤時浮標變金色；第一次釣到河伯鯰與熔岩龍鯉會掉紀念品

## 8. 魚簍、手帳與食譜

- [ ] 背包有魚簍時，釣到的魚直接進魚簍；紀錄魚與傳說魚留在外面
- [ ] 使用魚簍能開啟清單並取出一組魚，尺寸標記保留
- [ ] 漁歌手帳：圖鑑各水域頁面、紀錄次數與最大尺寸正常
- [ ] 手帳的潮汐頁顯示潮汐、月相，以及附近漁販今天想收的魚
- [ ] 第一次拿到一道料理時學會食譜；閱讀食譜殘頁學會一道並消耗殘頁
- [ ] 食譜頁列出工作站與材料，材料名稱都有翻譯 **★**（刪過一個語言鍵）
- [ ] 森羅手帳的漁歌分頁：皇鮪大體與冰湖主漁獲盤的堆疊數顯示 16 **★**

## 9. 工作站方塊

- [ ] 魚案板：放魚、用刀依序去鱗、剖腹、切片，產物正確；沒下刀前空手可取回
- [ ] 魚案板：大魚多一份、小魚少一份；無鱗魚直接從剖腹開始
- [ ] 曬魚架：掛魚、抹鹽變鹹魚、曬好後收下；下雨且無遮蔽時停止 **★**
- [ ] 魚露甕：先放鹽再放 4 條小魚或 4 份蝦米，發酵完成後用玻璃瓶或碗取出 4 份
- [ ] 蝦籠：放進水裡、放餌，過一段時間能取出蝦或螃蟹
- [ ] 漁具架：掛上與取回釣竿，耐久與附魔不變 **★**
- [ ] 漁獲秤：拿魚對它使用，指針依大小擺動
- [ ] 上面每一種工作站在有內容物時被打掉、被爆炸炸掉、被活塞推走：內容物都會掉出來，而且只掉一次 **★**

## 10. 魚缸與魚拓

- [ ] 魚缸：放進任何一種魚都看得到牠游動；空手取回時尺寸與紀錄保留 **★**
- [ ] 大魚缸：需要兩格空間，最多 4 條魚；打掉時魚缸與魚都還給你 **★**
- [ ] 打掉魚缸後沒有殘留在空中游的魚
- [ ] 魚拓：空白畫框只能掛牆上；拿魚對它使用後印出魚的樣子，魚還給你 **★**
- [ ] 魚拓外框依大小變化：銅、銀、金，紀錄魚多一個紅印

## 11. 宴席

- [ ] 每一種宴席都能放置：長形的朝遠離玩家的方向延伸，空間不夠時放不下並有提示音 **★**
- [ ] 每格可吃的口數正確，吃的時候回復飢餓並給效果
- [ ] 全部吃完後再用一次，整桌清掉並掉出容器 **★**
- [ ] 打掉沒吃過的宴席掉回原物品；吃過的只掉容器 **★**
- [ ] 兩人以上在同一桌吃，獲得生命提升與回復
- [ ] 漁船是純裝飾，不能吃

## 12. 冰釣

- [ ] 冰鑽對底下有水的冰使用，鑿出冰洞
- [ ] 任何釣竿都能往冰洞裡釣，釣到冰釣魚種
- [ ] 插旗浮標放進冰洞，魚咬鉤時紅旗彈起並有鈴聲；太晚收魚會跑掉
- [ ] 每人最多同時放 3 支插旗浮標

## 13. 趕海與海岸

- [ ] 海灘上有冒泡的沙地，用鏟子挖一定有東西；退潮時比較多
- [ ] 下雨時用鏟子挖草地或泥土，偶爾挖到蚯蚓
- [ ] 打掉牡蠣床掉牡蠣、紫菜礁掉紫菜，各 1 到 3 個；絲綢之觸掉方塊本身
- [ ] 用刀擊殺魷魚或發光魷魚掉魷魚

## 14. 生物

- [ ] 海鷗在海灘生成；生魚丟在地上且旁邊沒人時，海鷗會飛下來叼走 **★**
- [ ] 魚群：水面有細碎水花與跳魚，上空有海鷗盤旋；往中間拋竿咬鉤明顯變快 **★**
- [ ] 河邊的魚群旁會有鷺鷥站著 **★**
- [ ] 鸕鶿在河邊與紅樹林生成，可用生魚馴服；戴上頸環後會潛水叼魚回來，剪刀可取下頸環 **★**
- [ ] 流浪漁販：白天在水邊偶爾出現，先聽到鈴聲；交易畫面能買東西
- [ ] 拿魚對漁販使用能賣出整組，大魚價錢較高，他想收的魚雙倍；錢袋用完會搖頭 **★**
- [ ] 漁販扁擔上掛著今天想收的兩種魚

## 15. 與森羅廚房的連動

- [ ] 砧板、炒鍋、湯鍋、蒸籠、竹匾、茶壺：各做一道漁歌的料理
- [ ] 魚高湯桶與柴魚高湯桶能倒進湯鍋當湯底，湯面顏色正確
- [ ] 昆布茶能放在桌上、疊杯、喝掉
- [ ] 有特殊效果的料理吃完後獲得效果；歌萊鯉生魚片會短距離瞬移到安全的地面

- [ ] 找得到漁屋、棧橋、河邊小屋、紅樹林小屋，方塊沒有缺漏，箱子有戰利品
