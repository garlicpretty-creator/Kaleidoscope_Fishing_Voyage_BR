# 漁歌 1.5.0 遊戲內檢測表

`python tools/run_tests.py` 八項全過只代表檔案和程式邏輯沒問題。下面是**只能進遊戲看**的部分，照順序測。
建議開一個新的創造模式世界（另外用一個 1.4.0 的舊存檔測升級）。打勾後把結果回報，有問題附截圖或內容日誌。

指令小抄：`/time set 13000`（傍晚）、`/time set 18000`（半夜）、`/time set 0`（清晨）、`/weather clear`、`/locate biome mushroom_fields`、`/locate biome cherry_grove`、`/locate biome deep_dark`。

## 0. 載入
- [ ] 世界開啟時內容日誌沒有漁歌的紅字錯誤（設定 → 創作者 → 內容日誌）。
- [ ] 創造模式物品欄裡看得到新物品，圖示正常、名稱沒有 `kaleidoscope_fishing.xxx` 這種原始鍵。

## 1. 升級舊存檔（1.4.0 → 1.5.0）
- [ ] 舊的魚案板上切到一半的魚，可以繼續切，產物和以前一樣。
- [ ] 舊魚缸、大魚缸裡的魚還在、還在游。
- [ ] 舊的牡蠣床、紫菜礁是「長成」的樣子，空手可以採收。
- [ ] 舊魚露甕裡的蝦米：發酵完照常取出，或退回蝦米。

## 2. 潮汐鐘
- [ ] 手持潮汐鐘：指針方向、月相在左右哪一邊、拿在手上的位置正常。
- [ ] 掛牆潮汐鐘：可以掛上牆、方向跟著牆面；指針和手帳的漲退潮一致。

## 3. 魚案板
- [ ] 蝦、蟹、水母、整隻魷魚放得上去，每一刀外觀有變化、音效正常。
- [ ] 鮪魚三種部位、蝦米三步驟（鹽水蝦 → 竹匾帶殼蝦乾 → 案板搓殼）。
- [ ] 剖腹後空手取回「剖好的魚」，曬魚架只收它。
- [ ] 流星旗魚、新水域的魚放上去的模型是否合理（初版，照相近的魚複製上色）。

## 4. 木盆、曬鹽盤
- [ ] 木盆：水、鹽水、蛤蜊、魚卵、魚苗五種外觀都看得出來。
- [ ] 曬鹽盤：海邊、頭上沒遮蔽才會曬；三階段外觀。

## 5. 魚缸
- [ ] 熔岩魚缸會發光、不會點燃旁邊的東西；五種熔岩生物的模型與游法。
- [ ] 一般魚缸養牡蠣（靜止）與 1.5 新魚的模型。
- [ ] 大魚缸拿海帶、珊瑚、沙使用：缸底換成水草、珊瑚、沙底；兩格都跟著換；同一樣再用一次換回原樣。

## 6. 新水域
- [ ] 蘑菇島、櫻花樹林、深暗之域釣得到各自的魚；深暗之域在洞穴裡也算深暗之域。
- [ ] 新魚的收線小遊戲正常。

## 7. 天象
用 `/scriptevent` 沒辦法直接叫出天象，可以多睡幾晚，或在傍晚前後觀察（最多 11 晚一定有一次）。
- [ ] 流星雨：天上有流星劃過（大小、高度、亮度是否好看）。
- [ ] 極光：站在寒冷生物群系才看得到綠紫色光帶；溫暖地區看不到。
- [ ] 手帳潮汐頁在傍晚之後寫「今晚的天象」。
- [ ] 流星雨夜晚：海上釣得到流星旗魚、星鰭魚；挖冒泡沙地偶爾多一個星砂。
- [ ] 極光夜晚：冰洞釣得到極光銀魚。
- [ ] 星砂對玻璃浮球使用 → 發光玻璃浮球，會發光、打掉掉出發光浮球。

## 8. 牡蠣床、紫菜礁
- [ ] 放在海邊水裡的沙上：剛放下比較矮小，約一天長一階；成熟的才能採收。
- [ ] 縮小的兩個階段看起來清楚嗎（目前是把成熟模型縮小）。

## 9. 魚池
- [ ] 魚池餵食台的模型；放魚、放飼料時有聲音和水花；有飼料時食槽有飼料。
- [ ] 池裡游的魚：位置在水面下、大小合理、每隔一段時間換位置（**最需要看的部分**，不好看就改成保底方案）。
- [ ] 空手打開清單：魚種、尺寸、天數、「餓了」顯示正常；撈魚、撈魚卵。
- [ ] 隔幾天：魚長大（◆ 變多、標 ✿）；產卵時網籃裡有魚卵。
- [ ] 受精卵放進木盆清水：一天後魚苗、兩天後取出 2 條小魚。
- [ ] 敲掉、炸掉餵食台：魚、飼料、魚卵都掉出來，池裡的魚消失。
- [ ] 養殖魚（✿）賣給漁販只有六成。

## 10. 船釣（**風險最高**）
- [ ] 坐原版的船釣魚：正常拋竿、收線（加成要看數字不容易，至少確認沒有壞掉）。
- [ ] 釣魚小船：拿著對水使用能放下；坐上去能划、速度與轉向正常；模型的方向（漁燈在船頭）。
- [ ] 蹲下對小船使用打開魚艙（27 格）；魚簍滿了以後釣到的魚進魚艙。
- [ ] 打掉小船：掉出的是「釣魚小船」（不是原版的運輸箱船），魚艙的東西也掉出來。
- [ ] 拖網：拿漁網對小船使用，船尾出現網子；在深海航行一段距離，魚艙多了小魚；蹲下拿漁網再用一次收回。

## 11. 原版相容與其他
- [ ] 魚骨做骨粉、餵狼馴服；漁歌的魚餵貓馴服、補血。
- [ ] 漁刀的掠奪讓魷魚掉更多；耐久附魔；鐵砧修理。
- [ ] 釣竿的餌釣、海洋的祝福有效果（咬鉤變快、稀有魚多一點）。
- [ ] 漁販的訂單：交齊有獎勵；手帳潮汐頁顯示訂單進度。
- [ ] 傳說魚可以放進魚簍；紀念品與用它做的釣具。

## 12. 和草本、樂牧、豐收一起
每一項都要**同時啟用**那個模組和漁歌，另外再用一個沒有裝它們的世界對照。

**草本**
- [ ] 吃漁歌的料理，草本的寒熱值會變（例：清蒸螃蟹偏寒、焰鰭魚湯偏熱）。
- [ ] 1.5 新的豐收料理也有寒熱值（例：薑絲蛤蜊湯、花生小魚乾偏熱，黃瓜拌海蜇偏寒）。

**樂牧**
- [ ] 魚粉、小魚乾放得進樂牧的飼槽；樂牧版本支援的話，蝦米也可以。
- [ ] 樂牧登記的餌（雞胗、豬肝等）在漁歌釣竿上能用。

**豐收**（豐收 1.0.0 不回應握手，漁歌是看它的物品在不在）
- [ ] 內容日誌有一行 `kaleidoscope_harvest found (by its items)`。
- [ ] 7 道料理做得出來：
  - [ ] 薑絲蛤蜊湯（湯鍋：蛤蜊或吐沙蛤蜊 ×3、薑或薑絲）
  - [ ] 蔥燒魚（炒鍋：白肉魚片 ×2、蔥或蔥花、醬油）
  - [ ] 蒜蓉蒸蝦（湯鍋：蝦或溪蝦 ×3、大蒜或蒜末）
  - [ ] 檸檬魚（炒鍋：白肉魚片 ×2、檸檬、油）
  - [ ] 黃瓜拌海蜇（炒鍋：海蜇皮 ×2、小黃瓜、芝麻油）
  - [ ] 花生小魚乾（炒鍋：小魚乾 ×2、花生、辣椒）
  - [ ] 白蘿蔔魚丸湯（湯鍋：白肉魚片 ×2、白蘿蔔或蘿蔔塊、蔥或蔥花）
- [ ] 森羅廚房圖鑑的漁歌分頁看得到這 7 道，食材名稱顯示正常（不是原始鍵）。
- [ ] **沒裝豐收**的世界：這 7 道做不出來，內容日誌沒有紅字；圖鑑頁的說明寫著需要豐收。

**三個一起**
- [ ] 漁歌、草本、樂牧、豐收全部啟用，重開世界兩次，沒有重複登記的錯誤或卡頓。
